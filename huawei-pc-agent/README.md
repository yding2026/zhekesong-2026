# 华为 PC 营销软文智能体

初赛作品。自研 Agent 负责场景策略、平台规则、图文编排、事实核验和合规检查。ima 只作为华为产品事实和图片来源。

## 环境

- Python 3.10 及以上，只用标准库
- Node.js 18 及以上，用来运行官方 `ima-skill/ima_api.cjs`

## 配置

```powershell
cd huawei-pc-agent
copy .env.example .env
```

在 `.env` 里填写 ima 的 Client ID 和 API Key。凭证不要写入源码、README、截图或提交文件。

获取方式见赛题手册：登录已加入「任德耀新建华为PC知识库」的 ima 账号，打开 https://ima.qq.com/agent-interface 。

可选：如果要让大模型在资料原句上润色，再填写 `LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL`。不填也能运行，正文会直接引用知识库原句。

## 启动

```powershell
python agent/server.py
```

浏览器打开 http://127.0.0.1:8765

## 一次任务会做什么

1. 检查型号、人群、场景、平台是否齐全。不齐全就追问。
2. 按场景和平台生成内容策略。换场景会改切入点，换平台会改结构、语气、图片数量和行动引导。
3. 用官方脚本检索共享知识库。搜索为空时，改浏览目录并进入产品参数库。
4. 只提取资料原句。相近型号的资料不采用。同一事实点数字冲突时停止写入。
5. 编排标题、导语、正文、配图位置和行动引导。
6. 核验正文中的事实和图片型号，并检查绝对化宣传、虚假承诺、价格误导和竞品贬低。
7. 导出赛题要求的四段 Markdown。

## 自检

```powershell
python agent/selfcheck.py
```

自检使用的夹具不是华为资料，只用来确认代码会拒绝空泛型号、不编造参数、并让不同平台的策略不同。
