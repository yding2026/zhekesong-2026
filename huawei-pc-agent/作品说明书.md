# 作品说明书｜华为 PC 营销软文智能体

## 这个 Agent 做什么

服务对象是华为 PC 门店导购和内容运营。他们要针对不同人群、场景和平台写营销图文，但又不能把相近型号的参数和图片抄错，也不能编造价格和补贴。

ima 共享知识库「任德耀新建华为PC知识库」只负责提供产品事实和图片。下面这些事由自研 Agent 完成：

- 信息不够时追问，不直接写软文
- 识别人群、场景、购买阶段和内容目标
- 按公众号、小红书、门店朋友圈、门店海报改变结构、语气、图片数量和行动引导
- 检索资料并保留来源
- 只用资料原句编排图文
- 事实核验、图片型号核验、合规检查
- 按赛题四段格式导出

系统提示词在 `agent/prompts.py`，包含角色与任务、场景理解、平台规则、知识库约束、图片规则、生成要求、核验规则、合规规则。

## 架构

```
页面表单
  → agent/pipeline.py        闭环
      → agent/strategy.py    场景和平台策略
      → agent/ima_client.py  调用 ima-skill/ima_api.cjs
      → 事实提取、冲突检查、图文编排
      → 事实核验与合规检查
  → 四段 Markdown
```

调用的 ima 接口：

| 步骤 | 接口 | 用途 |
| --- | --- | --- |
| A | `search_knowledge_base` | 按名称查找「任德耀新建华为PC知识库」 |
| B | `get_knowledge_list` | 搜索为空时浏览目录，进入产品参数库 |
| C | `search_knowledge` | 按型号搜索资料和图片 |
| D | `get_media_info` | 读取原文或访问链接；笔记再调用 `get_doc_content` |

Client ID 和 API Key 只从环境变量读取。页面状态只显示「已配置」或「未配置」，不显示密钥。

## 本地运行

```powershell
copy .env.example .env
python agent/server.py
```

打开 http://127.0.0.1:8765 。填写型号、人群、场景和平台后点生成。结果可以复制或下载 Markdown。

公开代码仓库：https://github.com/yding2026/zhekesong-2026

魔搭：用队长自己的账号新建创空间或项目页，粘贴上面的仓库地址和本说明书，保证评审期内不用额外授权就能打开。页面上的项目名称、说明要和 GitHub 一致。

## 代码自检说明

`python agent/selfcheck.py` 使用一条虚构夹具，不是华为知识库，也不是参赛运行结果。它只确认三件事：空泛型号会被追问；正文里的数字必须来自给定资料，相近型号会被丢弃；开学季小红书和职场公众号、门店朋友圈的策略不同。当前自检通过。

## 已知限制

- 没有 ima 凭证时，不能检索共享知识库，也不会生成具体卖点。
- 官方脚本每天会检查技能更新。程序把检查日记到 `.ima-cache`，避免更新提示打断检索。
- 原文如果是 PDF 或带临时签名的链接，可能只能用到搜索高亮，读不到全文。
- 大模型润色是可选的。润色如果写出资料里没有的数字，或触发合规规则，会退回资料原句。
- 复赛需要的运行录屏还没有制作。
